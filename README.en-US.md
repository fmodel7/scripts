# Scripts FMODEL

**FMODEL - SERVICOS E CONSULTORIA EM TECNOLOGIA DA INFORMAÇÃO**  
F. Model · fmodel@fmodel.com.br

Public library for scripts, automation and practical documentation. **Windows Time 2.0.0:** [PDC and DOMHIER](scripts/configure-ntp-pdc/README.en-US.md), two standalone scripts with embedded root-PDC NTP sources or AD hierarchy, confirmation, backup, HTML reports and complete PT-BR/EN-US documentation.

**DHCP export/import:** [DHCP Transfer 1.0.0](scripts/dhcp-transfer/README.en-US.md) provides standalone scripts, guarded import, backups, HTML reports and individual PT-BR/EN-US guides. Real operations require Windows PowerShell 5.1; offline tests also run on PowerShell 7.

**Active Directory inventory/review:** [AD Health Report 1.2.0](scripts/ad-health-report/README.en-US.md) adds comprehensive AD/GPO/RSoP, identifiers, host/security, DNS/SYSVOL and backup evidence, offline HTML, 63 CSVs/JSON and optional ZIP. Includes a fictional example, Microsoft references and full PT-BR/EN-US manuals; coverage and unknown data remain explicit.

**Hyper-V inventory/review:** [Hyper-V Health Report 1.0.0](scripts/hyper-v-health-report/README.en-US.md) covers hosts/VMs/storage/VHD chains/network/checkpoints/Replica/security/events/cluster, with offline HTML, 54 CSVs/JSON, 23 contextual rules and optional ZIP. Includes synthetic examples and complete PT-BR/EN-US manuals. Live collection requires Windows PowerShell 5.1 x64; real infrastructure acceptance remains pending.
