# Credenciais e dados

Este repositório é público. Não incluir tokens, chaves de API, senhas, arquivos .env com valores, exportações reais de serviços, cabeçalhos de e-mail ou informações de clientes.

O .gitignore ajuda a evitar inclusões acidentais, mas não remove arquivos já rastreados e pode ser ignorado com git add -f. A revisão do conteúdo continua necessária.

Se uma credencial for exposta, revogar/substituir no provedor. Apagar o arquivo, a mensagem ou a captura não invalida a credencial.

Para relatar um problema sem expor informações sensíveis: fmodel@fmodel.com.br. Não enviar segredos ou dados reais no primeiro relato. O contato não representa um SLA ou certificação de segurança.
