# Contribuir com Scripts FMODEL

- Uma ferramenta por pasta, com README próprio e código/arquivos auxiliares juntos.
- Publicar apenas conteúdo que você tenha autorização para compartilhar.
- Preservar autoria e avisos/licenças de terceiros.
- Usar uma branch curta, revisar o diff e abrir um pull request.
- Atualizar o catálogo, versão e documentação ao alterar comportamento.
- Descrever o que realmente foi validado, com ambiente e resultados; não apresentar mocks como teste de produção.
- Não enviar segredos, exportações reais de serviços ou dados identificáveis de clientes.

Comece por [como adicionar um script](docs/COMO-ADICIONAR-UM-SCRIPT.md). Modelo: [README PT-BR](templates/powershell/README.md).

O repositório não possui licença de reutilização escolhida. A escolha deverá ser explícita; não atribuir MIT, Apache ou outra licença a código alheio sem verificar os direitos.
